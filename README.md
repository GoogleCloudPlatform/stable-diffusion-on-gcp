> [!IMPORTANT]
> The sample code in this repository has been removed.

The deployment manifests, container image definitions, Terraform modules and
Vertex AI training samples that were previously published here have been
removed. They contain security issues and depend on outdated third-party
components (an old AUTOMATIC1111 Stable Diffusion WebUI release and unpinned
WebUI extensions).

Earlier revisions remain in the Git history for reference only. They are not
supported and should not be deployed. If you operate an environment that was
built from this repository, we recommend that you shut it down.

For current guidance on running AI/ML workloads on Google Kubernetes Engine, see
[AI/ML orchestration on GKE](https://cloud.google.com/kubernetes-engine/docs/integrations/ai-infra).
